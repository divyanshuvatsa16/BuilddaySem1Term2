

# 🧠 Memory Matrix

A simple memory game built with **HTML, CSS, and JavaScript**.
Memorize the highlighted tiles and repeat the pattern correctly to level up.

---

## 🎮 How It Works

* Click **Start** to begin
* Memorize the green tiles
* Repeat the pattern
* One wrong click ends the game

---

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript (Vanilla)

---

## ✨ Features

* Progressive difficulty
* Score & level tracking
* Clean UI
* No external libraries
